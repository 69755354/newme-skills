# Propose a change · 提交修改

[Edit the English handbook](https://github.com/69755354/newme-skills/edit/bedrock-gateway-handoff/projects/bedrock-gateway/docs/handbook.en.md) · [编辑中文手册](https://github.com/69755354/newme-skills/edit/bedrock-gateway-handoff/projects/bedrock-gateway/docs/handbook.md)

## English

Anyone can read this public project. Sign in with your own GitHub account to propose changes. You do not need an invitation or to give the owner your username in advance.

1. Open the English edit link above. For another file, open it in the [project folder](https://github.com/69755354/newme-skills/tree/bedrock-gateway-handoff/projects/bedrock-gateway) and choose the pencil icon.
2. If GitHub offers **Fork this repository**, continue with your own fork. Edit the file, enter a short summary and choose **Propose changes** or **Commit changes** to your fork.
3. Choose **Create pull request**. Check that the **base repository** is `69755354/newme-skills` and **base branch** is `bedrock-gateway-handoff`. The compare branch belongs to your fork. Limit the edits to `projects/bedrock-gateway/`.
4. Send the pull-request link to the team. A maintainer with write access can review and merge it. Once merged, the changes appear on the project branch. The hosted website and downloadable files are published separately.

For a translated specification change, include both language files when possible or flag which one needs translation. Use fictional examples in this public repository.

## 中文

任何人都可以阅读。工程师用自己的 GitHub 账号登录就能提交修改建议。无需预先邀请，也无需先把账号发给项目负责人。

1. 点上方“编辑中文手册”。修改其他文件时，从[项目目录](https://github.com/69755354/newme-skills/tree/bedrock-gateway-handoff/projects/bedrock-gateway)打开文件后点铅笔。
2. 如果出现 **Fork this repository**，在自己的账号下创建副本。改好文件，写明变更内容，点击 **Propose changes** 或将修改 **Commit changes** 到自己的副本。
3. 点击 **Create pull request**。目标仓库选 `69755354/newme-skills`，目标分支（base）选 `bedrock-gateway-handoff`，来源分支选自己的副本。修改范围是 `projects/bedrock-gateway/`。
4. 把修改请求链接发给团队。有写权限的维护者审核合并后，项目分支即可看到变更。公开网站和下载文件单独发布。

修改规格时尽量同步中英文，或指出待翻译的部分。公开示例请使用虚构信息。
